# Historical presentation archive: CIP v5.1 corrections

This folder retains the historical slide deck and notes associated with the
v5.1 correction cycle. The current canonical framework remains CIP v5.2 at the
repository root.

## Purpose

- trace fidelity of prior documentation changes
- preserve the historical narrative around the v5.1 correction pass
- avoid conflating legacy review materials with the active framework reference

## Contents

- `cover.html`, `percentile.html`, `canonical_chain.html`, `p0_published.html`,
  `anomaly_distribution.html`, `v5_legacy.html`, `decision.html`,
  `final_control.html` — historical HTML slides.
- `slide_notes.json`, `slide_state.json` — associated presenter notes and
  slide-state metadata.

These files are preserved as legacy material only. They are not to be used as
the active framework reference.
