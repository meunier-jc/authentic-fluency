# Documentary audit presentation archive

This directory preserves the documentary-audit slide deck as historical
presentation material. It is not part of the active canonical CIP v5.2 text.

The active reference for the documentary audit pipeline is the
[English CI/CD integration guide](../../../docs/en/ci/documentary-audit.md).

## Contents

- `cover.html` — title slide.
- `principles.html` — audit principles.
- `adapter.html` — adapter behavior.
- `workflow.html` — pipeline workflow (references the archived architecture
  diagram under `archives/legacy-outputs/ci_documentary_audit_architecture.png`
  via its original build-time path).
- `rollout.html` — rollout steps.
- `security.html` — read-only security posture (references the archived
  anomaly chart under `archives/legacy-outputs/`).
- `slide_state.json` — slide-state metadata.

These files are preserved as legacy material only. Their internal image paths
point to the original build environment and are retained unchanged as
historical trace.
